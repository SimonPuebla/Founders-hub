# /polish

Final design pass on the specified area before shipping.

## Process

1. Fix any remaining impeccable bans (glassmorphism, gradient text, pure black)
2. Align to the project's card/color/type system
3. Tighten spacing rhythm — create variation, remove uniformity
4. Ensure hover/focus/active states exist for all interactive elements
5. Verify tabular numbers on all numeric data
6. Check empty states have useful copy, not just "No items"
7. Confirm reduced-motion is respected in any animations

## Rules

- Touch only what needs fixing — no refactoring unrelated code
- Match existing patterns in the codebase
- Changes must be verifiable by visual inspection
