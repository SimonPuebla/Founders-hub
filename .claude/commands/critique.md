# /critique

UX design review of the specified area. Feedback only — no edits unless asked.

## Evaluate

1. **Hierarchy** — Does the most important thing read first? Squint test: blur the screen, what survives?
2. **Clarity** — Is every label, button, and empty state immediately understandable?
3. **Emotional resonance** — Does the interface feel appropriate for its context?
4. **Density** — Is information density matched to use frequency? (daily-use = dense ok, occasional = breathe)
5. **Action affordance** — Is every interactive element obviously clickable/tappable?
6. **Consistency** — Same pattern used for same concept throughout?

## Output

3–5 specific observations. Each: what, why it matters, suggestion. No generic praise.
